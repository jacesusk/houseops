# HouseOps — Roommate Ticket System

A lightweight ADHD-friendly household task board for Jace, Sky, Mars, Roodi, Kookie, and guests.

## Included
- Today dashboard with Open / In Progress / Done columns
- Quick Add for low-friction capture
- Ticket details: title, notes, priority, due date, submitter, suggested assignee
- Claim / complete / reopen actions with actor name
- Full event history with timestamps
- Search and filters
- Household completion stats
- JSON export/import for moving or backing up the board
- Responsive mobile layout
- No login required

## Data note
This standalone build uses browser localStorage. That means each device has its own board. Export/import can move data between devices. True live multi-device sync requires a persistent database/backend, which is not included in this static build.
